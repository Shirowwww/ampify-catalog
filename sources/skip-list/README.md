# Skip list

## How to use it

- "Never play this" in the menu of a song, album, artist or playlist puts its name on your list.
- The button in the playback bar puts the song playing on the list and skips it.
- A song whose title, artist or album is on the list is skipped as soon as it starts.
- An album from the menu is skipped by its album only, an artist by the artist only, and a song by its Apple Music id when it is known, so a song with another title or a same-named album is not mixed up with it. When the id is not known, the song's title is used.
- A playlist, genre, composer or station from the menu stays on the list, but a playing track does not say which one it comes from, so it skips nothing.

"Skip list" in Apple Music's main menu (the "..." next to its name) shows the list, where each entry can be removed. It stays on this PC.

## Export and import

"Export" shows the list as JSON in a text field: select the text and copy it. A long list comes in several parts (Previous and Next); each part is a complete list of its own. On another PC, paste a part into "Import" and press "Add to the list". Entries already in the list are skipped, the list never goes over 500 entries, and the result says how many were added and skipped. Text that is not a JSON list is refused with a message and changes nothing.

## Settings

Skip live versions, remixes, and intros or interludes, judged from the song's title. All three are off at first.
