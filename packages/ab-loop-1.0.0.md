# A-B loop

Loops a passage of a song, to learn a riff, a verse or a dance step.

## How to use it

1. While the song plays, press the loop button in the playback bar where the passage starts.
2. Press it again where the passage ends. The button lights up, and the song goes back to the start each time it
   reaches the end.
3. Press it a third time to stop. Moving to another song stops it as well.

The tooltip of the button says what the next press does and which passage loops. Marked the wrong way round, the two
points swap. A passage shorter than a second is not taken.
